# PDF Chatbot

Chat with your PDFs — upload a document, ask questions, get answers with page references.

This repo contains two independent apps:

- **`/` (root)** — the React + Vite + Tailwind frontend. Fully functional on its own using a mock AI service, so you can run and demo it with no backend at all.
- **`/backend`** — an Express + LangChain + ChromaDB + Claude API backend, scaffolded and ready to wire up for real PDF question-answering (RAG).

## Quick start (frontend only, mock AI)

```bash
npm install
npm run dev
```

Open the printed local URL. Upload any PDF, click "Process PDF", and start asking questions — answers and source pages are generated by a keyword-based mock in `src/services/api.js` so the whole UI works before any backend exists.

## Connecting the real backend

```bash
cd backend
cp .env.example .env      # add your ANTHROPIC_API_KEY
npm install
npm run dev
```

The backend expects a running ChromaDB instance (see `CHROMA_URL` in `.env`). Once it's up, replace the contents of `src/services/api.js` with real `fetch()` calls to:

- `POST /api/upload` — multipart file upload
- `POST /api/process` — kicks off chunking + embedding + storage
- `POST /api/chat` — `{ documentId, question }` → `{ answer, sources }`
- `GET /api/history`

The request/response shapes in `api.js` already match these endpoints, so swapping mock functions for real `fetch` calls is a drop-in change — no other file needs to change.

## Notes

- Chat history and recent conversations persist to `localStorage` (`pdf-chat-history`, `pdf-chat-settings`) — the full PDF file itself is never stored there, only metadata.
- The frontend is fully responsive: a 3-column layout on desktop, a collapsible sidebar on tablet, and a PDF/Chat tab switcher on mobile.
- `npm install` requires network access, which this environment doesn't have — run it locally after downloading the project.
